# 墨澜创作台 · Windows 桌面版

面向小说作者的本地创作工作台，支持稿件编辑、章节与设定管理、AI 对话和创作任务。

**[下载最新安装包](https://github.com/CX0072/molan-desktop/releases/latest)**

1. 下载 Release 中的 Windows x64 ZIP，完整解压；或直接下载 Setup.exe。
2. 保存旧版稿件并退出软件，运行 Setup 完成安装。
3. 首次使用注册自己的账号并保存恢复密钥；管理员使用独立管理入口初始化。
4. 如需 AI 功能，配置自己的云模型 Key，或连接本机 Ollama。

安装包内置 Python 与 Electron，无需另外安装这两项环境。安装程序暂未代码签名。

## 更新与数据

软件内可检查本仓库的正式 Release，下载并校验 SHA256 后由用户确认安装。
稿件默认保存在用户授权的本机目录；请定期导出备份。
使用云模型时，所选对话和参考资料会发送给对应服务商，不应视为完全离线。

此仓库用于分发安装程序及公开说明，不包含开发者账号、Key、私人稿件或用户数据。
具体功能验证范围与已知限制请查看每个 Release 的说明。
